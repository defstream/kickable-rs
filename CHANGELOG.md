## v0.6.0 - 2026-06-01
### Added
- A GitHub Pages landing site (docs/index.html) with a vendored, prebuilt
  Tailwind stylesheet (docs/styles.css from tailwind.input.css).
- Filled in the mdBook documentation: Installation, Usage, and Docker pages.

### Changed
- Upgrade all dependencies to their latest releases, including breaking major
  bumps: axum 0.8, poem 3, tonic 0.14 (+ prost 0.14, tonic-prost-build), viz 0.11,
  warp 0.4, gotham 0.8, tower 0.5, tower-http 0.6, opentelemetry 0.32,
  axum-tracing-opentelemetry 0.38, and fluent 0.17.
- Migrate the build to cross-rs for the Linux and Windows targets, with an
  osxcross builder for the macOS targets; remove the hand-maintained
  joseluisq-based builder image dependency.
- Pin the Rust toolchain via rust-toolchain.toml (latest stable) for local, CI,
  and container builds.
- Vendor protoc via protoc-bin-vendored so no system protobuf-compiler is needed.
- Package Docker images from cross-built static musl binaries into a scratch image.
- Modernize GitHub Actions CI off the archived actions-rs/* actions onto
  dtolnay/rust-toolchain, Swatinem/rust-cache, cross, and rustsec/audit-check.
